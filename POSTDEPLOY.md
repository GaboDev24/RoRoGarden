 # Lista de Verificación Posterior al Despliegue (POSTDEPLOY.md)

Completá estos 5 pasos de verificación rápida en un celular real una vez publicada la app:

### 1. Abrir la dirección web
- [ ] Abrí el enlace en Chrome (Android) o Safari (iPhone).
- [ ] Comprobá que aparece la pantalla de bienvenida o el jardín con el sapo y la paleta de colores correcta.
- [ ] Revisá que no haya textos cortados ni barras de desplazamiento horizontal.

### 2. Instalar en la pantalla de inicio
- [ ] En Android: abrí Ajustes > "Instalar la app" (o menú ⋮ de Chrome > "Agregar a pantalla de inicio").
- [ ] En iPhone: tocá el botón de Compartir en Safari > "Agregar a pantalla de inicio".
- [ ] Verificá que en la pantalla de inicio del celular se vea el ícono del sapito con nombre **RoRoGarden**.
- [ ] Tocá el ícono para abrirla: debe abrirse a pantalla completa (modo standalone, sin barra de direcciones del navegador).

### 3. Prueba sin conexión (Modo avión)
- [ ] Con la app abierta o cerrada, activá el **Modo avión** del celular (sin Wi-Fi ni datos móviles).
- [ ] Abrí RoRoGarden desde el ícono de la pantalla de inicio.
- [ ] Comprobá que carga al instante sin internet.
- [ ] Hacé un Check-in o una pausa de respiración: los datos deben guardarse normalmente.
- [ ] Desactivá el Modo avión.

### 4. Prueba de respaldo (Exportar e importar)
- [ ] Andá a **Ajustes**.
- [ ] Tocá **"Descargar respaldo (JSON)"**: verificá que se descargue el archivo con fecha.
- [ ] Tocá **"Reiniciar solo el jardín"**: confirmá las dos veces.
- [ ] Tocá **"Seleccionar archivo JSON"** y cargá el archivo descargado: el jardín y los registros deben recuperarse intactos.

### 5. Probar una actualización futura
- [ ] Al subir una nueva versión del sitio, abrí la app instalada.
- [ ] Notá que la app **nunca se reinicia sola** en medio de una pausa ni borra registros.
- [ ] En Ajustes o en el jardín aparecerá una tarjeta suave avisando que hay una versión nueva lista para cuando quieras actualizar.
